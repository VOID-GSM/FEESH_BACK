# 🐟 FEESH
프로젝트 설명

## 💻 기술 스택
| 기술                  | 사용 목적                                                                         |
| ------------------- | ----------------------------------------------------------------------------- |
| **Java**            | 객체 지향적인 구조로 회원, 게시글 등의 기능을 객체 단위로 관리하고 안정적인 서버 개발을 위해 사용                      |
| **Spring Boot**     | Controller-Service-Repository 계층 구조를 적용하여 역할을 분리하고, 서버 개발 환경을 간편하게 구성하기 위해 사용 |
| **MySQL**           | 회원 정보, 게시글 등의 데이터를 저장하고 체계적으로 관리하기 위해 사용                                      |
| **Spring Web**      | 프론트엔드와 서버 간 REST API를 구현하고 HTTP 요청 및 응답을 처리하기 위해 사용                           |
| **Spring Data JPA** | 데이터베이스와 객체를 매핑하고 SQL 작성량을 줄여 CRUD 기능을 효율적으로 구현하기 위해 사용                        |
| **MySQL Driver**    | Spring Boot와 MySQL 데이터베이스를 연결하고 데이터를 저장·조회하기 위해 사용                            |
| **Spring Security** | 로그인 및 사용자 인증·인가를 구현하고 사용자별 접근 권한을 제어하기 위해 사용                                  |
| **Lombok**          | Getter, Setter, 생성자 등 반복적인 코드를 자동 생성하여 코드의 가독성과 개발 효율을 높이기 위해 사용              |
| **JWT**             | 로그인 후 사용자를 식별하고 인증 상태를 유지하며, 게시글 작성·수정·삭제 등의 사용자별 권한을 확인하기 위해 사용              |
